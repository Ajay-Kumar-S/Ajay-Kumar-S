# Synkron (EON Elevators)

Synkron is a starter platform for:

1. Natural-language meeting scheduling workflow with attendee email memory.
2. Technician troubleshooting guidance + issue tracking + PDF report download.
3. Sales first-visit checklist and challenge note logging.

UI follows a dark, industrial black + yellow Synkron style and is now split into option-based views (Dashboard, Troubleshoot, Guides, Meetings, Reports) instead of putting all modules on one screen.

## Run

Open `index.html` in browser.
